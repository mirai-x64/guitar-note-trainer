# guitar-note-trainer

ギター・単音メロディ練習のMVPプロトタイプ。ビルド不要の静的Webアプリ(HTML/CSS/vanilla JS、依存ライブラリなし)。

## 検証したい仮説

「診断的フィードバック+非罰的設計がDuolingo型ゲーミフィケーションより継続率を上げる」。
FFT採点そのものは差別化の核ではなく、挫折させない「寄り添い方」が核。

## 実装した核心機能

- **誤判定吸収層**: マイク入力を自己相関(ACF)でピッチ検出し、信頼度(clarity)を持たせる。
  無音・低信頼の区間は「不正解」と断定せず「判定できなかった」と中立表示する。
  同じ音符で低信頼が3回連続したら、自動判定を諦めて「録音して自分で聞き比べる」モードに切り替える。
- **技能カード単位の習熟度トラッキング**: 曲単位でなく、音符の性質(開放弦/フレット/弦移動/音符の長さ)
  から機械的に導出したタグ単位で正解率を追跡する。
- **3軸フィードバック**: 音程(セント差)とリズム(オンセット時刻のズレ)を判定する。
  強弱・ニュアンスは測定技術が未成熟なため、参考表示にとどめ採点には使わない(過剰な精度主張を避けた)。
- **プラトー検出と3手**: 技能カードごとに直近15件 vs その前15件の正解率を比較し、伸びが止まっていれば
  (a)停滞は普通だと明示 (b)その技能だけに絞ったドリルを既存譜面から再構成 (c)易しい既存譜面を80%速度で復習、
  の3つを提示する。
- **非罰的ストリーク**: 週単位(月〜日)の実施有無のみをドットで表示。炎アイコンや
  「このままだと連続記録が途切れます」のような危険訴求は実装していない。休止後の再開時も
  空白期間を煽らず「前回の練習: YYYY-MM-DD」とだけ表示する。
- **意図的に実装していないもの**: XP・レベル・バッジ・プッシュ通知。

## 練習譜面

5〜10曲固定(生成しない)。実在の曲ではなく、技能タグを計画的に配置したオリジナルの練習パターン
6種類(開放弦ウォームアップ/隣接フレット/2弦の橋渡し/ポジション移動/リズム挑戦/総合メロディ)。
開放位置(0〜4フレット)のみを使用。

## 動かし方

```
cd guitar-note-trainer
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開き、マイク許可を与える。HTTPS(またはlocalhost)が必須(`getUserMedia`の制約)。
GitHub Pagesでそのまま配信可能(ビルド不要、静的ファイルのみ)。

## 積み残し

- 自己相関のクラリティ閾値(0.85)・オンセット閾値はヘッドセットマイク1本での目視確認のみで、
  実際のギター音色・部屋のノイズでの再調整が必要(設計メモに書いた「技術検証タスク」は未着手)。
- 強弱・ニュアンス軸は測定(RMS)だけで採点に使っていない。音楽性フィードバックの核心部分は次段階。
- 非罰的ストリークの継続動機としての強さは未検証(5〜10人・1〜2週間の試用アンケートは未実施)。
- 実機(本物のギター+マイク)での動作確認はしていない。ブラウザの合成音(オシレーター)を
  マイク入力に見立てたE2Eテストのみで、ピッチ検出・オンセット検出・判定ロジックの経路確認を行った。
